# CV Express

Générateur de CV élégant en une seule page (HTML, CSS, JavaScript) : on remplit le formulaire, on ajoute sa photo et on télécharge son CV en PDF.

- 3 modèles (Moderne, Élégant, Bandeau), couleur au choix, fond coloré ou clair
- Aucune donnée n'est envoyée ni conservée : tout reste dans le navigateur
- Un seul fichier : `index.html`
