# CV Express

Générateur de CV professionnel en une seule page (HTML, CSS, JavaScript) : on remplit le formulaire, on ajoute sa photo et on télécharge son CV en PDF.

- 9 modèles (Moderne, Élégant, Bandeau, Exécutif, Épuré, Cartes, Tech, Prestige, Contraste)
- Couleur au choix, fond coloré ou clair, CV en français ou en anglais
- PDF au texte sélectionnable, adapté à tous les écrans
- Sections : expériences, formations, compétences, langues, projets, certifications, références
- Aucune donnée n'est envoyée ni conservée : tout reste dans le navigateur (sauvegarde facultative dans un fichier sur l'appareil)
- Un seul fichier : `index.html`
